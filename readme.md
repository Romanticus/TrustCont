# TrustCont - Система управления контактами

## Как запустить

### Настройка для разработки

1. **Установка зависимостей:**
   ```bash
   # Бэкенд
   cd backend && npm install
   
   # Фронтенд
   cd frontend && npm install
   ```

2. **Настройка переменных окружения:**
   
   Создайте файл `.env` в директории `backend/`:
   ```env
   API_KEY=test-api-key-123
   DATABASE_HOST=localhost
   DATABASE_PORT=5432
   DATABASE_USERNAME=trustcont_user
   DATABASE_PASSWORD=trustcont_password
   DATABASE_NAME=trustcont
   ```

    Создайте файл `.env` в директории `frontend/`:
    ```env 
   VITE_API_BASE_URL=http://localhost:3000/api
   VITE_API_KEY=test-api-key-123
    ```

3. **Запуск приложения:**
   ```bash
   # Запуск бэкенда (порт 3000)
   cd backend && npm run start:dev
   
   # Запуск фронтенда (порт 8000)
   cd frontend && npm run dev
   ```

## Затраченное время
- Бэкенд (NestJS): 2 часа
- Фронтенд (React): 3 часа
- Тестирование и отладка всего вместе: часа 2 ( учитывая попытки деплоя и докеризации)

**Итого около 7 часов**
